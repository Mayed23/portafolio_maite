Alke Wallet

Billetera digital para la gestión de clientes, cuentas y operaciones financieras.

Ver en GitHub →

Una solución web para gestionar información financiera

Alke Wallet es una aplicación web desarrollada con Django que permite a un operador administrar clientes, perfiles, cuentas, tipos de cuenta y operaciones financieras desde un panel web.

El proyecto combina desarrollo web, modelamiento de datos y reglas de negocio para mantener la integridad de la información durante las operaciones.

Python Django MySQL Bootstrap JavaScript
01

Actividad

Desarrollar una aplicación web para gestionar clientes, perfiles, cuentas y operaciones financieras como depósitos, retiros y transferencias.

02

Desafío

El reto central fue diseñar un modelo de datos relacional completo y coherente que reflejara un caso de uso financiero real, implementando los tres tipos de relaciones del ORM de Django (One to One, Many to One, Many to Many) de forma que tuvieran sentido de negocio genuino — no solo como ejercicio técnico. A esto se sumó el desafío de mantener la integridad financiera de los datos: evitar que el saldo se editara manualmente, bloquear eliminaciones que comprometieran la trazabilidad, y asegurar que operaciones como las transferencias actualizaran correctamente ambos extremos de la operación.

03

Solución

Se desarrolló una aplicación con Django utilizando modelos, formularios, vistas y plantillas para organizar la información y gestionar las operaciones desde un panel web.

  • CRUD de clientes, perfiles, cuentas y etiquetas.
  • Depósitos, retiros y transferencias.
  • Actualización automática de saldos.
  • Validaciones y reglas de negocio.
  • Autenticación y control de acceso.
  • Filtros para consultar transacciones.
  • Interacciones dinámicas mediante JavaScript.

¿POR QUÉ ESTE PROYECTO?

La evolución de una primera experiencia Front-end hacia una aplicación web más completa.

Elegí Alke Wallet porque representa la evolución de mi aprendizaje en desarrollo web. En una primera versión trabajé el Front-end de una billetera digital utilizando HTML, CSS, Bootstrap, JavaScript y jQuery.

En esta segunda versión llevé el mismo concepto a una aplicación desarrollada con Python y Django, incorporando MySQL, Django ORM, autenticación, operaciones CRUD, relaciones entre modelos y reglas de negocio.

Esta evolución me permitió pasar de construir la interfaz y la interacción de una aplicación a trabajar también en su estructura de datos, lógica y funcionamiento interno, conectando mis conocimientos de gestión de información y procesos con nuevas herramientas tecnológicas.
