PROYECTO ELEGIDO

Alke Wallet

Billetera digital para la gestión de clientes, cuentas y operaciones financieras.

Ver en GitHub →

Una solución web para gestionar información financiera

Alke Wallet es una aplicación web desarrollada con Django que permite a un operador administrar clientes, perfiles, cuentas, tipos de cuenta y operaciones financieras desde un panel web.

El proyecto combina desarrollo web, modelamiento de datos y reglas de negocio para mantener la integridad de la información durante las operaciones.

Python Django MySQL Bootstrap JavaScript
01

Actividad

Desarrollar una aplicación web para gestionar clientes, perfiles, cuentas y operaciones financieras como depósitos, retiros y transferencias.

02

Desafío

Construir una solución capaz de manejar información relacionada y aplicar reglas de negocio que protegieran la integridad de los datos.

  • Control de saldos.
  • Validación de operaciones.
  • Relaciones entre modelos.
  • Control de transferencias.
  • Historial de transacciones.
  • Restricciones para modificar o eliminar información.
03

Solución

Se desarrolló una aplicación con Django utilizando modelos, formularios, vistas y plantillas para organizar la información y gestionar las operaciones desde un panel web.

  • CRUD de clientes, perfiles, cuentas y etiquetas.
  • Depósitos, retiros y transferencias.
  • Actualización automática de saldos.
  • Validaciones y reglas de negocio.
  • Autenticación y control de acceso.
  • Filtros para consultar transacciones.
  • Interacciones dinámicas mediante JavaScript.
04

05

Principales aprendizajes

El desarrollo del proyecto permitió profundizar en la creación de aplicaciones web con Django y comprender cómo estructurar información y reglas de negocio dentro de una aplicación.

  • Modelamiento de datos relacionales.
  • Relaciones One-to-One, Many-to-One y Many-to-Many.
  • Creación de formularios y validaciones.
  • Autenticación y control de acceso.
  • Consultas mediante Django ORM y SQL.
  • Implementación de reglas de negocio.
  • Uso de JavaScript para mejorar la interacción.
